Below is a simple code snippet demonstrating a basic machine learning model using Python:


import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# Load dataset
data = pd.read_csv('data.csv')
X = data[['feature1', 'feature2']]
y = data['label']

# Split the dataset
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Initialize and train model
model = LogisticRegression()
model.fit(X_train, y_train)

# Make predictions
predictions = model.predict(X_test)
print(predictions)


This example shows the foundation of how machine learning operates and can be a great starting point for further exploration in AI.
